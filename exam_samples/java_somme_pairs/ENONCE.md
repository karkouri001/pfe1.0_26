# Examen Java: somme des nombres pairs

## Objectif
Implementer la methode suivante dans `Main.java`:

```java
public static int sommePairs(int[] valeurs)
```

La methode doit retourner la somme de tous les entiers pairs du tableau.

## Regles
- Si `valeurs == null`, retourner `0`.
- Si le tableau est vide, retourner `0`.
- Les nombres negatifs sont autorises.
- `0` est un nombre pair.
- Un nombre est pair si `nombre % 2 == 0`.

## Contraintes
- Classe attendue: `Main`
- Methode attendue: `public static int sommePairs(int[] valeurs)`
- Ne pas utiliser de lecture clavier ni sortie console pour la logique.
